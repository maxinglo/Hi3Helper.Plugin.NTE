# 国服登录组件兼容性

0.13.4 完成官方启动器 `1.0.7.1102 / ce6bd117` 的 SDK `2.0.9.0` 适配，并修复 0.13.3 遗漏的预登录版本检查。该启动器与 1.5.3 游戏资源配套使用，但启动器可以独立更新，因此不能只用游戏版本判断登录 SDK 是否兼容。

0.13.2 及此前版本只接受旧版启动器和 SDK 指纹，并要求 SDK 注册帧中的版本为 `2.0.8.0`。当官方启动器更新两个二进制文件后，登录组件会在启动游戏前拒绝这些文件；以前这个原因统一显示为“登录组件暂不可用”。

2026-11-05 核验来源为[官方版本配置](https://yhcdn2.wmupd.com/hd/publish_ob/launcher/Version.ini)及[该版本公开文件清单](https://yhcdn2.wmupd.com/hd/publish_ob/launcher/1.0.7.1102_1/AllFiles.xml)。本机文件的签名有效，大小与清单 MD5 均匹配：`NTEGame.exe` 为 36,717,664 字节、`44a324befcc20afe0ced8885c5a99521`；SDK 为 851,040 字节、`26bad3e965bc56abcce6fa416fce374c`。

本地原生验证通过新版 SDK 的公开初始化入口，使用合成应用参数检查了 796 字节环境握手、1244 字节注册帧、应用标识 1289、协议 2.0.9.0 与回调窗口归属。另直接加载发布包中的 LoginHost 程序集，对实际安装执行兼容性预检。上述检查不包含账号服务认证或游戏进入；这些仍需用户在实际登录界面验收。

## 统一的注册协议

最初的 0.13.3 只更新了启动预检和回调中的版本判断，预登录仍独立要求 `2.0.8.0`。新版 SDK 因此能启动游戏，但随后抛出 `InvalidDataException`，登录请求循环没有启动，点击“进入游戏”也不会弹出面板。

协议版本和应用标识现在统一定义在 `NteSdkProtocol`。`NteCnSdkCompatibility` 把已核验的启动器/SDK 指纹组合映射到这个协议对象，启动时选定一次。海外区域配置也显式关联其已核验协议，不再通过调用参数的默认版本选择协议。

协议对象统一校验并解码注册帧，得到短期持有的 `NteSdkRegistration`。回调窗口校验、静态配置解密和预登录初始化共享这同一对象，下游不再接收独立的版本字符串或重复解析注册帧。初始化完成即清理注册数据和临时应用密钥。

新增协议时，在协议定义和已核验文件映射中增加对应记录，并验证同一注册信息能连续完成配置解密及预登录初始化。回归测试同时覆盖旧版、新版、版本不匹配、未知版本和无效密钥元数据。兼容性检查不会仅因为注册帧自报了一个新版本就自动接受。

登录后台任务的异常也会交给现有组件显示，并保留宿主直到游戏退出。`runtime.json` 记录固定阶段、组件版本和异常类型，便于区分等待登录请求、初始化失败和面板初始化状态；不保存注册帧、密钥或账号。

## 后续维护约束

`NteRegionDefinition` 是主插件和 LoginHost 共用的安装标识来源，包括应用标识、启动器目录与主程序、游戏主程序路径、必需启动参数和登录通知编号。增加地区时，要同时通过原生预设、宿主和切服目标的一致性测试。Patcher 启动环境还要求应用标识与启动器目录成对匹配，即使错误组合下存在完整文件，也不会提供这些路径。

海外 SDK 的文件指纹、注册协议、配置密钥位置、认证服务版本、服务构建版本和设备统计版本放在同一个 `NteOverseasSdkProfile` 中。加载配置、创建认证参数和设备统计都使用选定区域的这一配置。国服匿名初始化和预登录共享 `NteCnSdkCompatibility.ServiceSdkVersion`；这个服务协议版本与本地 IPC 注册版本属于不同协议，不相互推导。

共享安装通过 `NteSharedProfile.Create` 保存资源版本、清单和实际分支。读取已有安装使用官方配置的 `LocalBranch`，完成更新使用实际下载分支，禁止把预设的引导分支写回已安装版本。回归使用未来的模拟分支验证切换、更新记录以及拒绝无效分支时不修改状态。

启动器请求的 CDN 镜像从 `NteConfigProvider.AllRegions` 中各地区的资源地址生成，保留请求路径；不再维护另一份域名配对表。旧的国服配置与资源列表 URL 属性也从同一组地址生成。地区中的 `DefaultBranch` 只用于初始化，实际下载仍由官方 PatcherConfig 发现当前分支。

账号存储中的版本标识、签名与加密格式、IPC 固定帧长度等是持久化或线上协议约束，保留明确校验；不能把它们当作可随意替换的运行时配置。上述一致性与回归测试不等于对未来未知 SDK、账号认证或完整游戏进入的验收。

## 错误提示与诊断

缺少游戏文件、已有游戏或官方启动器进程、未适配的 SDK，以及已有独立登录组件，分别显示对应提示，覆盖全部九种界面语言。

启动异常的最小报告保存到 `%LOCALAPPDATA%/Collapse/NTE/Diagnostics/last-startup.json`。报告只包含时间、组件版本、错误标识、异常类型和数值形式的原生错误码，不保存异常消息、命令行、SDK 数据包或账号信息。

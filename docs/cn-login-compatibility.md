# 国服登录组件兼容性

0.13.3 适配官方启动器 `1.0.7.1102 / ce6bd117` 的 SDK `2.0.9.0`。该启动器与 1.5.3 游戏资源配套使用，但启动器可以独立更新，因此不能只用游戏版本判断登录 SDK 是否兼容。

0.13.2 及此前版本只接受旧版启动器和 SDK 指纹，并要求 SDK 注册帧中的版本为 `2.0.8.0`。当官方启动器更新两个二进制文件后，登录组件会在启动游戏前拒绝这些文件；以前这个原因统一显示为“登录组件暂不可用”。

指纹必须成对匹配。旧版继续使用原协议；未知文件、混合版本，以及与选定组合不符的注册协议仍会被拒绝。回调仍校验客户端进程、窗口归属、应用标识与完整帧格式。

2026-11-05 核验来源为[官方版本配置](https://yhcdn2.wmupd.com/hd/publish_ob/launcher/Version.ini)及[该版本公开文件清单](https://yhcdn2.wmupd.com/hd/publish_ob/launcher/1.0.7.1102_1/AllFiles.xml)。本机文件的签名有效，大小与清单 MD5 均匹配：`NTEGame.exe` 为 36,717,664 字节、`44a324befcc20afe0ced8885c5a99521`；SDK 为 851,040 字节、`26bad3e965bc56abcce6fa416fce374c`。

本地原生验证通过新版 SDK 的公开初始化入口，使用合成应用参数检查了 796 字节环境握手、1244 字节注册帧、应用标识 1289、协议 2.0.9.0 与回调窗口归属。另直接加载发布包中的 LoginHost 程序集，对实际安装执行兼容性预检。上述检查不包含账号服务认证或游戏进入；这些仍需用户在实际登录界面验收。

## 错误提示与诊断

缺少游戏文件、已有游戏或官方启动器进程、未适配的 SDK，以及已有独立登录组件，分别显示对应提示，覆盖全部九种界面语言。

启动异常的最小报告保存到 `%LOCALAPPDATA%/Collapse/NTE/Diagnostics/last-startup.json`。报告只包含时间、组件版本、错误标识、异常类型和数值形式的原生错误码，不保存异常消息、命令行、SDK 数据包或账号信息。

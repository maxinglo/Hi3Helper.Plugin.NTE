# 地区、登录与共享安装

## 地区

| 地区 | 应用编号 | 官方组件目录 | 登录方式 |
| --- | --- | --- | --- |
| 中国大陆 | 1289 | `NTELauncher` | 手机验证码与保存账号 |
| 国际服 | 3000001 | `NTEGlobal` | 邮箱、Google、Facebook 与保存账号 |
| 台港澳 | 2000013 | `NTETW` | 手机验证码／密码、Google、Facebook 与保存账号 |

台港澳手机号区号来自官方公开目录：台湾 `+886`、香港 `+852`、澳门 `+853`。短信只在用户明确点击后请求，含糊失败也执行 60 秒冷却；切换模式或区号会清除临时密码／验证码。台服配置中的其他登录类型尚未全部接入。

每个地区分别保存账号、设备、上次选择和设置。跨地区的凭据解码、刷新与 SDK 投递均拒绝；相同账号编号不代表相同发行商身份。独立宿主直接启动游戏，并使用安装目录内经过校验的 SDK 和静态配置。

## 共用目录

国际服和台港澳可使用同一个安装根目录及 `Client`，一次激活一个地区。在 Collapse 的游戏设置中打开“服务器与共享安装”，选择目标地区，检查预览后再执行。

首次启用前结束游戏和官方启动器。组件会识别现有安装、读取两服官方资源清单、校验可复用文件，再下载必要的差异；准备完成后才激活目标地区。后续切换会复用已缓存版本，仍须为差异文件和临时文件保留足够空间。

共享状态位于安装根目录的 `.collapse-nte/`，包含活动地区、差异对象缓存和事务恢复信息。切换中断后，从原设置入口重新检查并恢复；不要手工混合两服清单或删除未完成事务。卸载一个地区时会保护仍在使用该目录的另一个地区。

本功能覆盖程序与资源切换，不转换账号。游戏自身的存档、截图和设置目录由客户端规则决定；不要据此推断两服角色或服务端数据可以互通。

## 验证边界

回归测试覆盖差异预览、共享文件复用、失败回滚、中断恢复、地区与账号隔离、PC 请求格式及 SDK 合成通信。界面夹具使用虚构窗口，不发送短信或认证请求。

实际 Google／Facebook 授权、短信投递、手机号认证、保存账号后重启恢复，以及共享目录切换后的两服实机运行仍须分别验证。公开服务配置成功、素材可下载或合成 SDK 回调成功不能替代进入游戏的证据。

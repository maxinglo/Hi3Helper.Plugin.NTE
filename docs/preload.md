# 版本预下载

0.13.0 接入 Collapse 的预下载入口、目标版本、总大小和已下载量。安装当前正式版后，在游戏页面使用宿主提供的预下载操作。

## 官方状态与下载计划

预下载状态来自当前正式分支的 `config.xml`：仅接受 `PreReleaseStatus=start`、安全的 `PreReleaseBranch` 和高于当前正式版的 `PreReleaseVersion`。插件不硬编码活动版本；当前游戏仍需更新、未安装或共享目录需切换地区时不开放预下载。开始下载前重新获取官方状态。

2026-11-04 国服公开配置为 `PC_140 / 1.4.18`，预下载目标为 `PC_150 / 1.5.0`。该次基础清单有 334 个文件、36 个变化文件，其中 9 个可用官方差分包。对于完整且匹配清单的 1.4.18 安装，计划预下载 11,723,251,704 字节，约 10.92 GiB；下载全部完整变化文件则约 46.96 GiB。实际计划也检查源文件是否存在、大小是否匹配，缺失文件可能需要完整下载。已安装可选基础资源延续现有版本保留规则。

资源清单必须与目标配置的 `listHash` 一致，差分清单使用 `diffHash` 校验。官方未提供可用差分时下载完整变化资源。

## 缓存与续传

- 内容缓存在 `<游戏目录>/.collapse_nte_preload/<AppId>/<MD5>.<大小>`，按应用和内容隔离，相同内容可跨预告版本复用。
- 支持取消、有效断点续传、HTTP Range、分块资源、Pak 范围读取、CDN 回退，以及现有下载调度和磁盘预算。
- 完整缓存核验大小和 MD5；同大小损坏文件不计为已完成。有效 `.tmp` 与 `.tmp.identity` 计入断点进度。
- 预下载只写缓存，不替换当前客户端文件，不提交正式安装版本或官方配置。游戏仍使用当前正式版资源。

## 正式更新

正式版发布后，安装器刷新分支和清单，优先复用内容匹配的缓存。完整资源再次核验后移入正式临时路径；有效的部分完整资源可继续续传。

差分合成需要先核验完整补丁及旧文件，使用固定内存窗口生成新临时文件；新文件的大小和 MD5 全部匹配后才替换旧文件。合成前单独检查输出空间。当前解码器支持实际观察到的无外部压缩 HDIFF13，采用上游 [HPatch 参考实现](https://github.com/sisong/HDiffPatch/blob/master/libHDiffPatch/HPatch/patch.c)的格式和 MIT 许可；许可随安装包提供。

损坏缓存、旧文件不匹配、未知差分格式或合成结果不符时回退到常规完整资源下载。未完成的差分包需在预下载阶段完成后才能合成；正式更新只复用已完整核验的差分。国服跨大版本分支提交只允许转入已安装官方配置此前公布的预下载分支，并核对预告版本。

## 验证范围

自动回归覆盖公共预下载入口、大小统计、取消续传、状态撤回、元数据一致性、跨分支复用、缓存与源损坏、合成失败不替换旧文件及部分完整资源迁移。差分解码另测四种 RLE、跨缓冲区、反向源覆盖、字面量间隔、损坏尺寸及取消；固定样本由上游 hdiffz 生成、hpatchz 独立应用，测试不依赖参考程序。

真实国服 CDN 已核验资源和差分清单，并下载校验 33,756,839 字节差分包及一个 Pak 内 3 字节样本。NativeAOT 版本的 COM 查询也使用隔离空文件夹具验证。以上不等同于完整预下载、大文件合成或游戏进入，命令见[构建与验证](development.md#预下载验证)。

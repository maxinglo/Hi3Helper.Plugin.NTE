# 登录说明与隐私

## 为什么需要自实现的登录服务？

本登录服务由异环插件提供，并非 Collapse 本体功能。为使 Collapse 无需启动官方启动器即可直接启动游戏，本插件自行实现登录界面及与游戏 SDK 的通信，并连接游戏官方服务完成认证。本插件在本机运行，未经游戏官方认可或授权，不使用开发者自建的账号服务器。

## 请明确了解封号风险

自实现的登录流程可能违反游戏服务条款，或触发风控与反作弊检测，导致登录受限、账号封禁，甚至永久封号。无法保证账号安全或持续兼容；此前成功登录也不代表没有风险。请在理解并愿意承担这些风险后继续。

## 禁止面向不特定人群公开推荐

因插件的特殊性，不得在任何公开社交媒体（如 B站、抖音、公开论坛等；国际版示例为 YouTube、TikTok、Reddit、X 等）面向不特定人群宣传或推荐本插件；上述仅为举例，并非完整清单。否则，作者将直接停止维护并删除仓库（删库跑路）。

## 会保存哪些数据？

“在此设备保存账号”默认勾选。勾选后会保存游戏／渠道用户 ID、登录令牌、渠道／地区／设备上下文、用于账号去重的身份摘要、上次选择的账号，以及官方提供的邮箱、昵称、打码手机号等可选显示资料。备注、本地记录 ID、保存时间和保护类型等属于可读元数据。密码与短信／邮箱验证码仅在内存中处理，不写入账号库；不勾选时，凭据仅在本次会话内使用。国际版另会保存一个随机生成的本地设备 ID（device.bin），即使未保存账号也会保留。

## 怎样保护，保存在哪里？

每个账号使用独立 AES-GCM 密钥加密凭据，默认由 Windows DPAPI CurrentUser 保护密钥；可选 Windows Hello 使用 Windows 管理的不可导出密钥。显示资料、身份匹配密钥、设备 ID 和上次选择另用 DPAPI 保护。国服目录：%LocalAppData%\Collapse\NTE\Accounts\；国际版位于该目录的 Global\ 子目录。文件包括 <记录ID>.json、.display、subject-key.bin、last-login.bin 和 Global\device.bin。加密无法防范以当前 Windows 用户权限运行的恶意程序。

## 数据发送给谁，还有哪些本机变更？

台服账号、设备 ID 和上次选择保存在独立的 `%LocalAppData%\Collapse\NTE\Accounts\Taiwan\` 目录。台服同样保留随机本地设备 ID，并向游戏 SDK 提供下文列出的国际版设备信息；即使不保存账号，设备 ID 仍会保留。手机号显示资料只保留区号和末四位，完整手机号、密码与验证码不写入账号库。台服可读设置位于 `%LocalAppData%\CollapseLauncher\Plugins\NTE\Taiwan\login.json` 和 `NteTaiwan\launch.json`。浏览器回调诊断在 `%LocalAppData%\Collapse\NTE\Diagnostics\` 中轮换记录时间、地区、阶段及字节数，不记录完整回调、令牌或账号。

认证所需的凭据、令牌、设备上下文及必要的版本／系统／硬件信息会通过 HTTPS 或本机游戏 SDK 交给游戏官方认证与游戏服务；服务端可看到你的 IP 地址。Google／Facebook 授权在系统浏览器打开官方页面，期间会临时修改 HKCU\Software\Classes 下的 wmgooglelogin 回调命令，正常结束时恢复原命令；异常退出可能留下该注册。本组件不向开发者上传账号，也不读取官方启动器账号库。游戏、浏览器和官方启动器有各自的数据处理与日志。 国际版还向游戏 SDK 提供计算机名称、网卡 MAC 地址、CPU／GPU 型号、内存与磁盘容量、分辨率、语言、地区和时区等设备信息。这些采集信息在本组件会话内存中使用，不写入账号库；官方 SDK 可能自行上报或记录。

仅国服：登录前由官方服务检查实名认证与防沉迷状态；无法确认或未通过时阻止登录，请通过官方渠道完成验证。本组件不收集或保存你的真实姓名或身份证号码。

## 其他设置、保存期限与删除方式

账号记录保留至你手动移除；官方令牌过期或撤销后仍需重新认证。可在“管理账号”中移除账号。退出游戏和 Collapse 后，删除 %LocalAppData%\Collapse\NTE\ 可清除本组件的账号、设备与知悉记录；Hello 密钥由 Windows 管理，通过移除账号清理。可读 JSON 设置位于 %LocalAppData%\CollapseLauncher\Plugins\NTE\ 下：login.json、Global\login.json、NteCN\launch.json、NteGlobal\launch.json。知悉版本与时间位于 %LocalAppData%\Collapse\NTE\login-notice.json。公开媒体缓存及更新／完整性数据可能保留在插件和游戏目录；登录卡片背景截图仅在内存中使用。删除不等于安全擦除，也不会清理浏览器、官方服务或云端备份。

## 不放心时，可以使用官方登录流程

点击“使用官方启动器”，或前往 Collapse → 游戏设置 → 启动设置，启用官方启动器后台静默启动。官方启动器必须位于当前游戏安装目录内：国服为 NTELauncher，国际版为 NTEGlobal，台服为 NTETW（NTETWGame.exe）。确认后会保存该区服设置并关闭当前游戏，下次启动改用官方后台／直接启动流程；需要登录、验证或更新时，官方仍可能显示必要窗口。选择官方启动器不会标记为已知悉，也不会删除已保存账号。
